# Ovim 1.3.0

Ovim 1.3.0 adds a native desktop workbench alongside the terminal editor, richer
Git review, and reading views for code and Markdown.

## Highlights

- **Native GUI:** editor and browser tabs, an AI chat composer, model selectors,
  test and debugger controls, workspace layout persistence, and desktop clipboard
  and image support. Native packages accompany the terminal and GUI binaries.
- **Git review:** `<Leader>gd` and `:GitDiff` open the same branch diff review.
  Configure the comparison with `:set pullbase=<branch>`, including path-specific
  overrides and Lua configuration. Gutter change signs use that comparison too.
  Blame remains author annotations, with hover details, commit colors, and
  click-through commit diffs. Diff buffers include a scroll indicator.
- **Reading views:** `:set pseudo` / `:set nopseudo` toggle a source-mapped reading
  view for Java and Markdown. The GUI renders Markdown as formatted documents.
- **Walkthrough discussions:** Esc from a follow-up answer returns to its step.
  Press `t` to reopen the thread and `[` / `]` to browse its questions. Answers
  continue streaming while hidden. Esc from the step dismisses the walkthrough.
- **AI models:** `/model codex_astra` selects the optional `gpt-6-astra` profile.
  Existing model defaults remain unchanged.
- **Languages and navigation:** Properties, Eclipse preferences, INI, EditorConfig,
  Git config, and XML support; `]D` / `[D` visit errors only. Definition navigation
  remembers the originating tab for `:q` until a manual tab or file change.

## Reliability

This release includes fixes for Unicode cursor and selection behavior, repeat
and undo semantics, LSP startup and transport handling, stale GUI updates, and
background picker test synchronization. Headless API sessions require
authentication, and interactive sessions keep their network API closed.

## Installation

Use the archive for your operating system and CPU to install `ovim` and
`ovim-gui`, or choose a native desktop package. Homebrew users can update through
the Ovim tap once its formula points to this release.

The macOS desktop packages are unsigned. Embedded browser tools require the
native GUI host; they are not provided by the terminal frontend. Model access
continues to depend on the signed-in account.
